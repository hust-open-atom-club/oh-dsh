# Agent Note: 将固定 DSH runtime 升级到 0.1.2-rc.1

Status: implemented

[English](2026-09-11-dsh-0.1.2-rc.1-upgrade.md) | 中文

## 问题

固定 runtime 此前停在 `0.1.2-alpha.3`，因为 alpha.3 之后的每个版本都
移除了所有已发布 dsh-TUI 依赖的 `Session.events` getter。dsh-TUI v0.10.0
交付了 Session-projection 适配并在 peer 范围里声明 `0.1.2-rc.1`，rc 线
重新可达。另一件事：模型目录里的临时条目
`deepseek-v4.1-flash-expires-on-0910` 把退役日期写死在 id 里，而
DeepSeek 已在 2026-09-10 的更新日志中以官方 id `deepseek-flash` 提供
V4.1 Flash。

## 决策

- 固定 `0.1.2-rc.1`，并跟随同线的已发布 surface 依赖：dsh-TUI v0.10.0
  （嵌套 dsh-auth 94fdf81；dsh-ecosystem-spec 仍为 d28c267）、Better
  Sidebar v0.18.1（包含原 v0.18.0-alpha.0+59 固定点另加 156 个提交）、
  dsh-context v0.47.0——0.1.2-rc.1+ 兼容矩阵上的最后一个版本
  （v0.48.0 已把 V3 基线移到 dsh 0.1.5-rc.1，而没有任何已发布 TUI 支持
  该线）。
- 三个 surface 补丁层中的临时条目替换为官方 `deepseek-flash` id（排在
  目录首位，名称 `DeepSeek-V4.1-Flash`，text+image）。补丁层保留，
  因为 runtime 自身的 `DEFAULT_MODELS` 要到 0.1.5-rc.1 才包含
  `deepseek-flash`（已解包核对 0.1.2-rc.1、0.1.3-alpha.2、
  0.1.5-alpha.1、0.1.5-rc.1）。
- TUI 补丁层的 `llm-deepseek` 行在 `models` 之外重述 TUI bundle 自己设
  的键（`apiKeyEnv`、`baseURL`、`thinking: enabled`、
  `reasoningEffort: max`）：补丁行会整行替换 config，而 schema 对
  thinking/effort 没有默认值，只写 models 的行会在终端 surface 上静默
  丢掉它们。契约测试现在固定这些键。
- TUI 重挂载行 `oh-tui-renderer` 对齐上游 `dsh-tui` 行的 inject 列表，
  含 `tuiThemes`。
- 删除 `cc-tui` disabled 行（dsh-TUI 0cecfd4 退役了旧命名，v0.10.0 的
  patch 里已无此行）及其测试断言。`TUI_SUPERSEDED_BUNDLES` 再保留一版，
  继续从用户 profile 清理 `dsh-cc-tui` bundle。
- 删除 workspace 里 `dsh-session-persistence-sqlite` 的 override：
  v0.10.0 以精确版本 `0.1.1-rc.2` 固定它（此后无新版本；rc.1 移除了
  runtime 的 SQLite 会话后端），精确版本不存在漂移问题。
- v0.10.0 构建产物的适配接缝：`LogoV2` 签名随 whale 欢迎重构增加了
  intro/whaleIdle/working；Chat.js 的 inline 布局 flex 行增加了
  `marginRight: -pageInsetX`；`LEGACY_DATA_DIR` 随 ~/.dsh-cc 迁移退役
  消失。

## 后果

- 三个 surface 运行在同一条 0.1.2-rc.1 树上（frozen install，213 条
  override，214 个 `@deepseek-ai/dsh-*` 包）。
- 模型目录补丁层仍是发行版自有的目录；当内置 `deepseek-flash` 的
  runtime 线可达时整体删除（0.1.5-rc.1 需要 dsh-TUI 发布声明支持；
  sidebar v0.19.0 / context v0.49.0 已面向它适配）。
- DeepSeek 目前把退役的 `deepseek-v4-flash` /
  `deepseek-v4-flash-vision-exp` 临时路由到 V4.1 Flash，并将在
  2026-09-14 12:00（北京时间）后同样路由 `deepseek-v4-pro`，因此目录
  里的旧条目在 0.1.5 升级移除前只是展示用途。
- Nix：rev 与两个 npm tarball 哈希已更新；fetchFromGitHub 的 nar 哈希
  与两个 fetchPnpmDeps 哈希仍需在可运行 nix 的主机上通过真实的
  `nix build` 刷新（已在 nix/oh-dsh.nix 的 pin 旁注明）。

## 考虑过的替代方案

- **直接固定 0.1.5-rc.1（npm latest）。** 否决：没有任何已发布 dsh-TUI
  声明 0.1.5 线（peer 上限 `0.1.2-rc.1`），且 0.1.5 线退役了我们的
  客户端插件仍在使用的插件契约（ctx.agent、Inbox 类、conversation
  slot）——让固定 surface 跑在未声明的线上正是 0.1.2-alpha.3 note 拒绝
  过的事。
- **彻底删除模型目录补丁层。** 本轮否决：0.1.2-rc.1 的内置目录仍没有
  `deepseek-flash`，在 0.1.5 线落地前每个 surface 都会失去 V4.1 条目。
- **把 sqlite override 留在 0.1.2-alpha.2。** 否决：那会覆盖 v0.10.0
  有意为之的精确 `0.1.1-rc.2` 固定，偏离上游 workspace。
