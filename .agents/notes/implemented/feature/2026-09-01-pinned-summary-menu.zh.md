# Agent Note: 完善固定摘要菜单

Status: implemented

[English](2026-09-01-pinned-summary-menu.md) | 中文

## Problem

固定摘要插件能够展示会话上下文，但浮动菜单目前只是纯文本快照。长摘要
不易扫描，Markdown 和代码失去结构，用户也无法复制摘要、打开所属会话或
查看完整文本。会话数据加载中或不可用时，界面反馈也不够清晰；当前焦点和
ARIA 行为对键盘用户支持不足。所有改进都必须保持为轻量的 Web 客户端能力，
并且不能破坏侧边栏或既有固定摘要服务契约。

## Decision

固定摘要客户端仍是由既有 `locale` 和 `sessions` 服务支持的浏览器插件。公开
的 `PinnedSummary` 接口保持不变（`isOpen`、`setOpen`、`subscribe` 和
`toggle`）；更丰富的行为在浮动界面内部实现，不增加第二个状态仓库，也不
新增宿主 API。

界面从当前会话快照派生内容。优先使用非空的压缩摘要，没有时使用最新助手
文本作为有界回退。会话列表和对话数据按可用情况提供标题、状态、工作目录、
provider/model、工具活动以及更新时间或消息时间等元数据。缺失字段保持缺失，
不凭空推断。加载中、错误、空会话、无会话和无摘要状态都有明确的本地化文案。

摘要文本通过 DOM 节点和 `textContent` 渲染，并使用无依赖的小型 Markdown 展示
层处理段落、列表、引用、行内代码和围栏代码块。预览长度稳定限制为 480 个
字符，正文放在 220px 的独立滚动区域中，面板最大高度为 500px，因此操作按钮
无需滚动整个菜单即可看到。本地化控件可以在这个有界区域内展开或收起完整摘要。
不把不可信内容赋给 `innerHTML`；只有 `http` 和 `https` URL 才会生成链接。浏览器
支持时使用剪贴板复制，并报告成功或失败；剪贴板权限不应成为渲染前提。

菜单增加复制当前摘要和通过现有 `sessions.open(id)` 打开对应会话的明确操作。
在运行时提供真实的摘要生成操作之前，有意不添加刷新或重新生成按钮。打开和
关闭继续支持点击外部与 Escape；打开时把初始键盘焦点放到关闭控件，关闭时
恢复之前的焦点元素，并通过 ARIA 属性提供对话框名称、隐藏状态、按钮名称和
实时状态更新。面板保持非模态，以便应用的常规键盘导航可以继续移出面板。现有的
`data-oh-dsh-summary-pinned` 标记和工具栏 toggle 继续负责侧边栏与摘要之间
的互斥联动。

本次改动严格限定在 Issue #180 的固定摘要界面及其必要测试范围内。不增加无关
功能、不新增运行时 API，也不添加没有真实后端操作支持的刷新按钮。共享辅助函数
保持精简，测试有意保持最小且聚焦行为，避免重复覆盖每一个渲染分支。

## Alternatives considered

**增加完整 Markdown 依赖。** 否决：这个有界预览只需要 Markdown 的小子集，
引入渲染器会增大包体积，并增加一个 HTML 清理边界。

**继续对所有内容使用 `innerHTML`。** 否决：摘要和链接来自会话数据，显式构造
节点可以审计标记和 URL 策略，并防止意外执行 HTML 或脚本。

**扩展 `PinnedSummary` 或新增运行时摘要 API。** 否决：现有服务和会话绑定已经
能够支持所需交互；修改公开契约只会扩大 Desktop/Web 集成面，却没有即时收益。

**显示只重新渲染本地数据的刷新/重新生成按钮。** 否决：这会暗示运行时能够
执行它实际不能执行的工作。只有在存在真实且可观测的生成 API 后，菜单才应增加
该操作。

**用独立路由或重量级模态框替换浮动菜单。** 否决：当前锚定面板已经属于侧边栏
工作流，并具备定位和互斥联动钩子；独立路由会让快速查看变慢，还会重复导航状态。

## Consequences

固定摘要在扫描和键盘操作方面更实用，同时不新增包，也不改变服务边界。用户
可以从预览跳到来源会话，并复制完整摘要；过长或格式异常的输入仍保持有界且
安全。代价是需要维护更多本地化文案以及少量额外的 DOM/CSS 状态，
剪贴板行为仍受浏览器权限影响。

实现把 provider/model、工具和时间数据明确视为可选的展示上下文，不对会话排序、
推断信任，也不把流行度或状态字段变成安全决策。Markdown 支持范围有意保持有限；
不支持的结构仍以可读文本呈现，不会被静默解释。

## Testing

纯派生测试固定压缩摘要优先级、助手回退、预览截断、元数据提取和生命周期状态。
既有布局契约测试已同步有界摘要正文；由于仓库没有该插件的 DOM 测试 harness，
没有新增独立 DOM 回归测试或只扫描源码的测试，测试套件保持精简。
已在 Node 24 项目运行时执行仓库门禁：`pnpm run typecheck`、固定摘要/布局聚焦测试、
`pnpm test`（330 个通过，10 个平台跳过）、`pnpm run build`、
`pnpm run verify:agent-notes`、`pnpm run verify-translation-pairing` 和
`git diff --check` 均通过。浏览器 smoke 命令已尝试，但无图形服务器的 headless
环境没有 X server 或 `$DISPLAY`，Chromium 无法启动；这是环境限制，不是源码或
构建失败。
