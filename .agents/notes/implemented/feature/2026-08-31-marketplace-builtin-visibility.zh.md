# Agent Note: 插件市场默认隐藏内置插件

Status: implemented

[English](2026-08-31-marketplace-builtin-visibility.md) | 中文

## 问题

插件市场把受保护插件与可安装插件并列展示，但事务管理器实际上会拒绝修改
这些插件。

## 决定

目录归一化现在同时发布 `builtin` 与 `protected`。目前所有受保护条目都属于
内置插件，但 `builtin` 只控制展示，`protected` 仍是修改权限边界。Desktop 与
Web 默认隐藏内置插件，并通过合成的内置视图显示它们，不覆盖目录的原始分类。
隐藏内置插件时，如果当前选择的合成分类或原始分类不再存在，则恢复为“全部”。
TUI 采用相同默认值，并提供 `Ctrl+B` 显示开关。显示选择只保留在当前进程内。

## 考虑过的替代方案

没有直接使用 `protected` 同时表达授权和展示，因为两种语义未来可能分化。
没有把原始分类替换成“内置”，因为这样会丢失目录元数据。

## 后果

协议增加一个必填布尔值。浏览器状态视图把内置插件计为已安装，但不会创建插件
市场安装记录，也不会把它们计为已停用或可更新。浏览器分类选择不会保留随内置
条目一起消失的值。直接命令仍由现有的 `protected` 事务检查拒绝。
